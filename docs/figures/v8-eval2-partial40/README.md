# V8 common40: public aggregate projection

This directory publishes six PNG/SVG figure pairs, four numerical CSVs and a derived `values.json`. The original12 image files and three CSVs (`metrics`, `case-mapping`, `training`) are byte-identical to the locally checked result. `per-case.csv` preserves all120 rows and all metric/outcome fields, replacing private raw-trace paths with the original record index and a canonical record SHA-256. Those raw records are not included here. `training.csv` describes the historical1344-update saved V8 training run; this evaluation/partial analysis performed zero new training.

The three matched arms handled **30/40,30/40 and33/40** tasks correctly. All27 failed arm/case records are retained. The selected120 records contain657 known calls. The original experiment remains incomplete:136 of144 task records were completed, with765 known responses and one started call without a response. The16 completed baseline-tail records, seven unstarted candidate tasks and one ambiguous candidate task are excluded from this matched analysis without replaying any call.

Selection is the fixed first40 original case IDs common to all arms, not a selection by quality. It is retrospective and nonrandom;20 of24 families are covered. The omitted families are `exchange_available_refusal`, `exchange_fallback_missing_payment`, `exchange_missing_email` and `missing_email_payment`. Do not infer those branches, all48 cases, production reliability or general safety from these results. Both compared adapters were already tuned; the case set is authored synthetic data under the same policy.

The public summary is [`public-summary.json`](../../../reports/v8-eval2-partial40/public-summary.json). This publication contains aggregate and case-level numerical outcomes, not new raw model text, prompts, tokens, private cloud snapshots, operator/account/resource receipts or human authorization. Its derived JSON/CSV hashes differ from the private originals and **do not recertify the original full-source seal or enable full token/business replay**. PNG/SVG figures retain their original scientific values.
