# ResolveDesk 第八轮：修复、续训与三组独立对照

代码、数据与评测计划已在模型执行前**封存**，目前**没有 V8 模型训练或评测结果**。[测试集](../training/v8/test_dataset.json)已独立保存为 48 题、24 类各 2 题；作者没有读取 V8 训练或验证正文，没有调用候选模型。测试覆盖依据已知历史失败类别，因此这是同作者、共享策略的合成测试，不是外部人工基准或完全未知分布。

本轮将分别处理证据引文不精确后的纠正、把“original order”误当退款方式、商品名称尾缀与规格歧义，同时保留授权拒绝、未知授权、补邮箱、必要转人工、确认拒绝及退货/换货意图区分。正确与否必须等待实际对照；现在不承诺提升幅度。

## 测试数据与隔离

48 个世界各有独立实体、一个订单和一个有限目录；目录包含原款与两个候选款式，共轮换六种服饰类别。两题是真正的两个选项未决定：初始规格金标为 `unknown`，必须追问 `new_option`，脚本回答提供明确的目录原文，不由后端替用户选择。八题未指定支付方式，即使出现原订单/原商品等描述，初始支付金标仍为 `unknown`。

| 预声明口径 | 分母 |
| --- | ---: |
| 全部独立测试世界 | 48 |
| 明确条件授权 / 明确拒绝 / 未知授权 | 12 / 12 / 24 |
| 非授权任务（拒绝或未知） | 36 |
| 可完成换货 / 缺货回退 / 必要转人工 / 补邮箱 | 14 / 4 / 16 / 8 |
| 初始换货任务 | 30 |
| 需要补充信息的任务 / 字段数 | 18 / 20 |
| 真实规格歧义、必须追问 | 2 |
| 全体预设接受 / 拒绝选择 | 24 / 24 |
| 非转人工任务的接受 / 拒绝选择 | 16 / 16 |

这些是数据分母，不是模型成功数；业务子集会重叠。操作意图澄清的脚本回答始终保持用户初始操作，缺货回退题也仍回答 `exchange`，不把预期退货结果当成改写用户请求的授权。

使用明确的十个历史文件检查，与此前 **1,323** 个案例的订单世界、实体、初始句、去实体指令骨架、目录标签及实际 V7 初始投影均无交集；48 题自身也不共享订单或实体。测试不进入训练/验证或本地演示。测试作者只读取开发集单向特征哈希，不读取开发题面和答案；开发作者交付后，另行做了只读全量隔离审计，所有作者样本字节保持不变。对 96 个训练场景和 48 个验证场景的案例、订单、实体、目录、初始句、骨架、公共输入及 V8 实际初始投影比对均无交集。

旧 V7 工作流的确定性 CPU 参考已验证 48 题在每题 12 次总动作内可完成，共 260 次参考动作。它只证明策略可行性，**不是模型正确率、模型推理结果或 SFT 数据**。新 V8 工作流已通过 37 项工程回归测试及训练/验证的 278 条 CPU 教师轨迹核查；这些不替代真实模型对照。自然请求与实际补充回复用于观察引文准确性；主测试不强制注入错误，只有实际发生引文拒绝时才计纠正情况。

## 三组匹配对照

| 标识 | 权重 | 工作流 | 目的 |
| --- | --- | --- | --- |
| `prior_weights_old_flow` | 上轮固定 final1344 | V7 | 保留基线 |
| `prior_weights_new_flow` | 相同上轮权重 | V8 | 观察工作流变化 |
| `v8_weights_new_flow` | 本轮固定 final1344 | V8 | 相同工作流下观察续训变化 |

每组 48 题，共 144 条完整任务轨迹。每题 **12 次 TOTAL 模型调用**，包括错误、拒绝、纠正及所有客户回合；每次最多生成 512 token，贪心解码，不加入未计数的修复、预热或为通过而重试。两种增量分别报告，不能把控制器改进记作微调收益。

首次七个原始字段、解析和枚举错误在任何修复前计分；后端归一化、被接受的记录与模型自行纠正分别报告。保留明确授权召回与未授权 YES 的独立分母、重复追问尝试/送达、全部相同动作重复、必要与不必要转人工、补字段、总调用和所有残余失败。授权审计继续区分原始调用、提议、提交与最终订单状态，不相加，也不以零观察证明生产安全。

## 已确定的候选训练配置

从上轮固定 final1344 适配器初始化，保持同一既有 4bit 权重解码得到的 FP16 冻结基座、FP32 LoRA 主参数、rank 8、最后 8 层、3,670,016 个可训练参数。Adam 参数保持上轮设置，学习率降为 **2×10⁻⁶**，种子 **202610288**，完成 **1,344 次真实更新**；普通 token 权重 1、permission 值 8、reason 值 4，提示与 padding 不计损失。

完整上下文上限在模型执行前确定为 **3,200 token**，以保留最长 3,143 token 的复杂操作恢复轨迹；监督投影窗口仍为 192，不截掉监督目标。开发数据含 **1,100 条去重训练 pair**。预声明的 1,344 步均衡采样只覆盖 **888/1,100 条独立 pair、96 个源场景**：216 条意图/记录修复样本全用，884 条执行样本中使用 672 条。此为 CPU 计划投影，不是实际完成的训练覆盖，也不能表述为训练遍历了所有 pair。

**只使用固定 final1344，不选检查点。**验证集仅用于监控和是否采用的判断，不根据本测试选点、重训或修改样本。完整配置、初始化精确数值、实际更新计数及最终权重身份需要实际核验。训练耗时和后续评测耗时目前只有估计，不作为结果发布。
