# Publication status

This public snapshot is based on local source commit `96d35eb`. Its completed model-quality evidence is CUDA independent evaluation run002: 48 new authored synthetic tasks, 96 arm/task records, and 509 completed model calls. See the project README and bilingual report for all gains and regressions.

V8 is experimental and unfinished. Its four-update CUDA smoke test completed; the formal run stopped before model loading at zero optimizer updates because a smoke-report CLI path was relative. No V8 validation or test model call completed. The planned three-arm comparison has no result yet. New recovery helpers under local review are excluded from this public snapshot.

Private account screenshots, continuation state, duplicate cloud snapshots, partial evaluations, local databases, credentials and model weights are excluded. Private account authorizations, account balances and private local build paths are omitted from the public projection. Public build-command receipts use portable interpreter markers; they do not reproduce the original private execution commands. The public reports are explicit privacy projections, with removed metadata and original/public hashes recorded in public-redactions.json; they do not inherit the original local byte seal. Scientific trajectories, model tokens, scoring and outcomes are retained. Large JSON/JSONL evidence is losslessly gzip-compressed for GitHub; run `python scripts/unpack_evidence.py` to verify the public artifact SHA256 and restore the paths before tests or reports. Operational files excluded here are retained in the original local archive; this export does not replace that archive.
